# Introducing programming languages
- A programming language gives us precise rules for telling a computer what to do i.e. writing programms
- We want to make it easy to write fast, correct, and readable.
# What is a programming language?

- There are many different things we can call a programming language. This makes it hard to define them in a way that covers exactly the things we want.
- Common features of programming languages
	- x86 assembly language is used to program the processor
	- Its basic operations correspond directly to hardware
	- We think of a program as the processor changing values stored in registers
